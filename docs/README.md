Welcome to the Nunaliit wiki!

If you're seeking a step-by-step tutorial on running your own Nunaliit atlas, please consult the [Nunaliit Tutorial Wiki](https://github.com/GCRC/nunaliit_tutorial/wiki).

For a more comprehensive reference manual on building atlases with Nunaliit, please consult the [[Nunaliit Documentation for Atlas Builders]].

If you have a question, please [open a new issue](https://github.com/GCRC/nunaliit/issues/new) in GitHub. We will label the issue as a question, and close them when we think they have been answered.

[Answered Questions](https://github.com/GCRC/nunaliit/issues?q=is%3Aissue%20label%3AQuestion%20state%3Aclosed)

[Open Questions](https://github.com/GCRC/nunaliit/issues?q=is%3Aissue%20state%3Aopen%20label%3AQuestion)

If you want to discuss Nunaliit with our community of developers and users, you may register with a free [matrix](https://matrix.org) homeserver to participate in our [Nunaliit chat channel](https://matrix.to/#/#NunaliitAtlasBuilders:gcrc.carleton.ca).

If you are interested in helping to enhance Nunaliit or fix bugs, the [[Nunaliit Documentation for Developers]] provides more detailed information on building and contributing code.
